# 华语辩论赛 AI 系统 - MVP 实施计划

## 项目目标

在现有 AI Agent 系统基础上，实现一个**最小可行产品（MVP）**的华语辩论赛 AI 系统。所有输出保存到 `workspace/debate/` 目录。

## MVP 核心原则

1. **简化到极致**：只实现最核心的功能  
2. **文本长度代替时间**：用字数控制代替复杂的计时系统（文档中的「分钟」仅用于换算字数上限，**不实现真实计时**）  
3. **硬编码流程**：严格按照标准赛制流程  
4. **文件输出**：所有记录保存到文件  

## MVP 功能列表

### 必须实现（核心）

1. 标准赛制流程控制（硬编码状态机）  
2. 四个辩手 Agent（继承或组合现有 `BaseAgent` / 项目内统一的对话能力，与 `OpenFriend` 使用的模型配置保持一致）  
3. 文本长度控制（约定：`1 分钟 ≈ 250 字`，见下文各环节上限）  
4. 文件输出到 `workspace/debate/`  
5. 团队内部通信：**准备阶段**采用「独立思考 → 队内交流 → 轻量 research（类 Deep Research，可大幅简化）」，过程写入共享缓冲或团队日志文件  

### 暂不实现（刻意简化）

1. 复杂的通信网络  
2. 实时计时系统  
3. 发言权转让机制  
4. 多种赛制支持  
5. 完整 Deep Research：多轮澄清、长程记忆、引用去重与评测报告（准备阶段只做**固定轮次 + 可选工具调用**的裁剪版）

## 核心设计

### 1. 文本长度控制（代替时间）

```
换算（仅用于设定字数上限，非运行时计时）：
1 分钟 ≈ 250 个汉字（或约 500 个英文字符，按产品二选一统一）

各环节字数上限示例：
- 一辩立论（对应约 3 分钟口语量）：不超过 750 字
- 攻辩环节（对应约 1.5 分钟/轮）：单轮提问+回答合计不超过 375 字（可再拆成提问/回答子上限）
- 自由辩论（单次约 30 秒口语量）：单次不超过 125 字
- 总结陈词（对应约 3 分钟）：不超过 750 字
```

### 2. 准备阶段：独立思考 → 队内交流 → 轻量 research（类 Deep Research，MVP 裁剪）

**目标**：赛前不是「每人一句话了事」，而是先**队内想清立场与论点**，再**互相看见并补充**，最后做一次**简化版 deep research**——像典型 Deep Research 流水线那样「**提出问题 → 检索/工具 → 合并要点 → 产出一份可引用的队内核稿**」，但 **MVP 只保留固定步数与字数上限**，不接完整多轮检索与引用系统。

**建议子流程（顺序固定，便于实现与落盘）**：

| 子步骤 | 做什么 | MVP 简化约定 |
|--------|--------|----------------|
| **A. 独立思考** | 每名辩手在**仅含辩题 + 本方立场**的上下文中，各写一段「个人要点」 | 不引用队友、避免一上来从众；每段单独字数上限（如各 150～250 字） |
| **B. 队内交流** | 将 A 的摘要（或全文拼接）作为共享上下文，辩手**按轮次**回应、补充、对齐口径 | 仍用 `speak` + 共享 `StringBuilder`/日志；每轮每人一段，字数上限略低于立论 |
| **C. 轻量 research** | 由**固定角色**根据 B 列出 **1～3 个检索问题**；若项目内已有 `WebSearchTool`（或等价工具），**每队调用 0～N 次**（建议上限 2～3），把**短摘录**追加进日志；再由**固定角色**（建议一辩）根据「讨论 + 摘录」写 **《队内核稿》** | 不做多轮自动追问；检索失败则跳过，仅用讨论内容写核稿 |

**落盘建议**：除 `pro_team_prep.txt` / `con_team_prep.txt` 外，可增加 `*_prep_research_snippets.txt`（检索摘录）或把摘录并入主 prep 文件同一节，便于后续立论把核稿拼进 `context`。

**与后续环节的衔接**：一辩立论时的 `context` 建议优先带 **《队内核稿》** 与**交流阶段共识**，独立思考草稿可只作附录或省略，以控制 token。

```java
// 示意：准备阶段仍可用共享缓冲串起 A→B→C
public class DebateTeam {
    private final List<BaseAgent> members;
    private final StringBuilder teamChatLog;

    /** A：独立思考 — 依次追加，上下文不包含他人草稿（实现上可每次只传辩题+立场） */
    void privateThinking(String topic, String stance) { /* ... */ }

    /** B：队内交流 — 传入 A 的汇总文本，辩手轮次发言并写入 teamChatLog */
    void teamExchange(String topic, String draftsSummary) { /* ... */ }

    /** C：轻量 research — 生成检索问题、可选调工具、一人写核稿并写入 teamChatLog */
    void lightResearch(String topic, DebateToolBridge tools) { /* ... */ }
}
```

### 2.1 其它环节的通信（非准备阶段）

攻辩、自由辩论等仍按状态机驱动；需要时只读准备阶段落盘的**核稿/摘要**，不必重复跑 research。

### 3. 硬编码流程（状态机）

`DebatePhase` 中的数字若保留，建议表示**环节总字数预算或阶段权重**，与上文「分钟」脱钩，避免读者误以为已实现计时；或在枚举中只保留描述字符串，字数全部由 `DebateCoordinator` 按环节常量配置。

```java
public enum DebatePhase {
    PREPARATION("准备"),
    PRO_OPENING("正方一辩"),
    CON_OPENING("反方一辩"),
    CROSS_EXAM("攻辩"),
    FREE_DEBATE("自由辩论"),
    CONCLUDING("总结"),
    END("结束");

    private final String description;

    DebatePhase(String description) {
        this.description = description;
    }

    public String getDescription() {
        return description;
    }

    public DebatePhase next() {
        return switch (this) {
            case PREPARATION -> PRO_OPENING;
            case PRO_OPENING -> CON_OPENING;
            case CON_OPENING -> CROSS_EXAM;
            case CROSS_EXAM -> FREE_DEBATE;
            case FREE_DEBATE -> CONCLUDING;
            case CONCLUDING -> END;
            default -> null;
        };
    }
}
```

### 第 2 步：实现辩手 Agent

**交付物**：四方辩手可生成「不超过 `maxWords`」的发言；提示词与 `team`、`role` 绑定。

```java
// DebaterAgent.java - 简化版
public abstract class DebaterAgent extends BaseAgent {
    protected final String team; // "pro" or "con"
    protected final int role;    // 1,2,3,4

    public DebaterAgent(String team, int role) {
        super();
        this.team = team;
        this.role = role;
        this.setName(team + "_" + role);
    }

    public String speak(String topic, String context, int maxWords) {
        String prompt = buildPrompt(topic, context, maxWords);
        return generateResponse(prompt);
    }

    private String buildPrompt(String topic, String context, int maxWords) {
        return String.format("""
            你是%s方%d辩，当前辩题：%s
            上下文：%s

            请发表不超过%d字的发言。
            注意：你的发言会累计到团队总字数中。

            发言内容：
            """,
            team.equals("pro") ? "正" : "反",
            role,
            topic,
            context,
            maxWords
        );
    }
}
```

### 第 3 步：实现主协调器

**交付物**：按 `DebatePhase` 顺序执行；各环节落盘；`CON_OPENING` 能消费正方立论摘要或全文（注意下文「已知问题」）。

```java
// DebateCoordinator.java - 简化版
public class DebateCoordinator {
    private final String debateId;
    private final String topic;
    private File outputDir;

    private final List<DebaterAgent> proTeam;
    private final List<DebaterAgent> conTeam;

    public void runDebate() {
        outputDir = new File("workspace/debate/" + debateId);
        outputDir.mkdirs();

        DebatePhase phase = DebatePhase.PREPARATION;
        while (phase != DebatePhase.END) {
            executePhase(phase);
            phase = phase.next();
        }

        saveResults();
    }

    private void executePhase(DebatePhase phase) {
        log("=== 进入阶段：%s ===", phase.getDescription());

        switch (phase) {
            case PREPARATION:
                teamPreparation(proTeam, "正方立场");
                teamPreparation(conTeam, "反方立场");
                break;

            case PRO_OPENING:
                String proSpeech = proTeam.get(0).speak(topic, "", 750);
                log("正方一辩：%s", proSpeech.substring(0, Math.min(100, proSpeech.length())));
                saveSpeech("pro", "1", proSpeech);
                break;

            case CON_OPENING:
                String conSpeech = conTeam.get(0).speak(topic, proSpeech, 750);
                log("反方一辩：%s", conSpeech.substring(0, Math.min(100, conSpeech.length())));
                saveSpeech("con", "1", conSpeech);
                break;

            case CROSS_EXAM:
                for (int i = 0; i < 4; i++) {
                    DebaterAgent attacker = (i % 2 == 0) ? proTeam.get(1) : conTeam.get(1);
                    DebaterAgent defender = (i % 2 == 0) ? conTeam.get(2) : proTeam.get(2);

                    String question = attacker.speak(topic, "进行攻辩提问", 375 / 2);
                    String answer = defender.speak(topic, "回答：" + question, 375 / 2);

                    log("攻辩轮次%d：%s 提问，%s 回答", i + 1, attacker.getName(), defender.getName());
                }
                break;

            case FREE_DEBATE:
                freeDebate();
                break;

            case CONCLUDING:
                String conConclusion = conTeam.get(3).speak(topic, "进行总结陈词", 750);
                String proConclusion = proTeam.get(3).speak(topic, "进行总结陈词", 750);

                log("反方四辩总结：%s", conConclusion.substring(0, 100));
                log("正方四辩总结：%s", proConclusion.substring(0, 100));
                break;
        }
    }

    private void teamPreparation(List<DebaterAgent> team, String position) {
        StringBuilder teamLog = new StringBuilder();
        teamLog.append("=== 团队准备（思考 → 交流 → 轻量 research）===\n");
        teamLog.append("立场：").append(position).append("\n\n");

        // A. 独立思考：每人一段，提示词中明确要求勿引用队友
        StringBuilder drafts = new StringBuilder();
        for (DebaterAgent member : team) {
            String draft = member.speak(topic, "仅根据立场独立列出要点，勿引用队友", 220);
            drafts.append(member.getName()).append("：").append(draft).append("\n");
            teamLog.append("[思考] ").append(member.getName()).append("：").append(draft).append("\n");
        }

        // B. 队内交流：基于全队思考摘要再发言一轮
        String exchangeContext = "已知队友独立思考如下：\n" + drafts;
        for (DebaterAgent member : team) {
            String reply = member.speak(topic, exchangeContext + "\n请做回应、补充或对齐口径（队内交流）", 280);
            teamLog.append("[交流] ").append(member.getName()).append("：").append(reply).append("\n");
            exchangeContext = exchangeContext + "\n" + member.getName() + "：" + reply;
        }

        // C. 轻量 research：示例由二辩列检索问题、可选 Web 搜索、一辩写核稿（角色可配置）
        String queries = team.get(1).speak(topic, "根据上述队内讨论，列出1到3个检索问题，每行一个", 200);
        teamLog.append("[检索问题]\n").append(queries).append("\n");
        String snippets = optionalWebSearch(queries); // MVP：每队 0～2 次调用；无工具则返回空串
        teamLog.append("[检索摘录]\n").append(snippets).append("\n");

        String brief = team.get(0).speak(
            topic,
            "结合队内交流与检索摘录，写《队内核稿》：核心论点、论据关键词、预判对方可能攻击点",
            700
        );
        teamLog.append("[队内核稿]\n").append(brief).append("\n");

        saveTeamLog(team.get(0).team, teamLog.toString());
        // 可选：saveResearchSnippets(team.get(0).team, snippets);
    }

    /** MVP：封装对 WebSearchTool 等的调用，次数与超时在此限制 */
    private String optionalWebSearch(String queries) {
        return "";
    }

    private void freeDebate() {
        int proWordsLeft = 1000;
        int conWordsLeft = 1000;
        boolean proTurn = true;

        int round = 1;
        while (proWordsLeft > 0 && conWordsLeft > 0) {
            if (proTurn && proWordsLeft > 0) {
                int words = Math.min(125, proWordsLeft);
                DebaterAgent speaker = selectSpeaker(proTeam, round);
                String speech = speaker.speak(topic, "自由辩论发言", words);

                proWordsLeft -= countWords(speech);
                log("正方发言（剩余%d字）：%s", proWordsLeft, speech.substring(0, Math.min(50, speech.length())));
                saveFreeDebate("pro", speaker, speech);
            }

            if (!proTurn && conWordsLeft > 0) {
                int words = Math.min(125, conWordsLeft);
                DebaterAgent speaker = selectSpeaker(conTeam, round);
                String speech = speaker.speak(topic, "自由辩论发言", words);

                conWordsLeft -= countWords(speech);
                log("反方发言（剩余%d字）：%s", conWordsLeft, speech.substring(0, Math.min(50, speech.length())));
                saveFreeDebate("con", speaker, speech);
            }

            proTurn = !proTurn;
            round++;
        }
    }

    private int countWords(String text) {
        return text.replaceAll("[^\\u4e00-\\u9fa5]", "").length();
    }
}
```

**实现时注意**：`executePhase` 中 `proSpeech` 在 `case PRO_OPENING` 内声明，`case CON_OPENING` 若在同一 `switch` 中直接引用，Java 要求扩大作用域（例如在进入 `switch` 前声明 `String proSpeech = ""` 并在立论分支赋值）。文档保留原伪代码结构，编码时按语言规则调整。

### 第 4 步：文件输出

**交付物**：按辩手/环节写入 `workspace/debate/{debateId}/`，并有一份可读的 `transcript.txt` 或等价汇总。

```java
public class DebateFileWriter {
    private final File baseDir;

    public DebateFileWriter(String debateId) {
        this.baseDir = new File("workspace/debate/" + debateId);
        this.baseDir.mkdirs();
    }

    public void saveSpeech(String team, String role, String content) {
        File file = new File(baseDir, String.format("%s_%s.txt", team, role));
        try (PrintWriter out = new PrintWriter(file)) {
            out.println("=== " + (team.equals("pro") ? "正方" : "反方") + role + "辩发言 ===");
            out.println("时间：" + new Date());
            out.println("字数：" + content.length());
            out.println("\n" + content);
        }
    }

    public void saveTranscript(String content) {
        File file = new File(baseDir, "transcript.txt");
        try (PrintWriter out = new PrintWriter(file)) {
            out.println(content);
        }
    }
}
```

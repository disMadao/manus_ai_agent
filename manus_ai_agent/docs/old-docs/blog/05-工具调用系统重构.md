## agent循环

之前的react agent直接复用的 openmanus中的设计，构造的一个类，然后各种继承，太麻烦了，直接用一个while(true)，都不用设置最大循环时间。

每次在这个里面做这么几件事情：

> 1. 上下文压缩
> 2. 调用模型，流式获取输出
> 3. 解析模型返回的工具调用
> 4. 执行工具，获取结果
> 5. 把结果追加到对话历史。
> 6. 如果没有新的工具调用， 结束，否则继续

现在需要考虑的是，工具的按需加载发生在agent循环中的那一步？

每一次对话都是这么一个过程吗？

现在有一个问题是，如果用agent loop的话，工具调用的消息怎么办？开始注入的advisor无法感知到连续两条消息是一个loop中的还是两个loop中的，因为一个loop中的消息显然需要压缩处理。这个感觉spring ai设计的就不对劲。它的设计就默认了所有消息一样似的，这里的话，需要存储的之后首条用户消息和最终的消息。中间的工具调用过程都不用存储。

## 流式传输预加载工具

Claude Code 为什么能边流边执行？

**核心区别**：Claude API（Anthropic 官方）提供的是**结构化事件流**，不是纯文本流。

```txt
传统文本流式：  "I will" → " read" → " the" → " file" → "..."
                 ↑ 你不知道这是什么，要等完整输出才能解析

Claude 事件流：  {type: "content_block_start", block: {type: "tool_use", name: "read_file"}}
                 {type: "content_block_delta", delta: {partial_json: '{"path": "/a.txt'}}
                 {type: "content_block_stop"}  ← 收到这个=一个工具块完整了
                 ↑ 立即知道这是工具调用，可以马上执行
```


在agent loop中，输出都是流式的，而且Anthropic SDK提供了流式传输的是json 类型，所以可以解析，看是否是工具调用，如果当前接收的是工具调用，就可以直接调用加载调用工具了，不用等模型全部输出完毕，这个spring ai好像做不到，和更底层的SDK有关。

使用anthropic sdk的java版本的一个实现，**流式工具执行器**：

```java
import java.util.concurrent.*;
import java.util.*;

/**
 * 边流式接收事件边执行工具
 */
public class StreamingToolExecutor {

    // 追踪每个 content block（按 index 区分）
    private final Map<Integer, BlockBuilder> blocks = new ConcurrentHashMap<>();
    
    // 工具执行 Future（按 tool_use_id）
    private final Map<String, CompletableFuture<String>> toolFutures = new ConcurrentHashMap<>();
    
    // 线程池
    private final ExecutorService executor = Executors.newCachedThreadPool();

    /**
     * 处理每个流式事件
     */
    public void handleEvent(RawMessageStreamEvent event) {
        
        if (event instanceof ContentBlockStart e) {
            // ========== 块开始 ==========
            int index = e.index();
            ContentBlock block = e.contentBlock();
            
            BlockBuilder builder = new BlockBuilder();
            
            if (block instanceof ToolUseBlock toolUse) {
                builder.type = "tool_use";
                builder.toolUseId = toolUse.id();
                builder.toolName = toolUse.name();
                builder.inputJson = new StringBuilder();
            }
            
            blocks.put(index, builder);
            
        } else if (event instanceof ContentBlockDelta e) {
            // ========== 块增量 ==========
            BlockBuilder builder = blocks.get(e.index());
            if (builder == null) return;
            
            if (e.delta() instanceof InputJsonDelta jsonDelta) {
                // 累积 JSON 片段
                builder.inputJson.append(jsonDelta.partialJson());
            }
            
        } else if (event instanceof ContentBlockStop e) {
            // ========== 块结束 —— 关键！ ==========
            BlockBuilder builder = blocks.remove(e.index());
            if (builder == null) return;
            
            if ("tool_use".equals(builder.type)) {
                // 工具块完整了，立即异步执行！
                String toolName = builder.toolName;
                String toolUseId = builder.toolUseId;
                String inputJson = builder.inputJson.toString();
                
                CompletableFuture<String> future = CompletableFuture.supplyAsync(
                    () -> executeTool(toolName, inputJson),
                    executor
                );
                
                toolFutures.put(toolUseId, future);
            }
        }
    }
    
    /**
     * 实际执行工具
     */
    private String executeTool(String name, String inputJson) {
        // 解析 inputJson，调用对应工具...
        return "工具结果";
    }
    
    /**
     * 获取所有工具结果（流结束后调用）
     */
    public Map<String, String> getAllResults() {
        Map<String, String> results = new HashMap<>();
        toolFutures.forEach((id, future) -> {
            try {
                results.put(id, future.get());
            } catch (Exception e) {
                results.put(id, "Error: " + e.getMessage());
            }
        });
        return results;
    }
    
    static class BlockBuilder {
        String type;
        String toolUseId;
        String toolName;
        StringBuilder inputJson;
    }
}
```

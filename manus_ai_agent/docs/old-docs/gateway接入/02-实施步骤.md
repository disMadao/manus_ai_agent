## 步骤 1：安装 OpenClaw

**负责人**：运维/后端
**依赖**：Node.js 22+, pnpm
**预计耗时**：30 分钟

### 操作

```bash
# 安装 OpenClaw
npm install -g openclaw

# 验证安装
openclaw --version

# 初始化配置目录
openclaw init

# 启动 Gateway（先不配置 QQ，验证基础运行）
openclaw gateway start
```

### 验证标准
- `openclaw gateway status` 显示运行中
- 访问 `http://localhost:18789` 可打开 Dashboard

---

## 步骤 2：配置 QQ Bot 官方插件

**负责人**：运维/后端
**依赖**：步骤 1 完成（可与步骤 3 并行）
**预计耗时**：30 分钟

### 凭证准备

去 [QQ 开放平台](https://q.qq.com) 创建/使用已有的机器人应用，获取：
- `app-id`：应用 ID
- `app-secret`：应用密钥
- `token`：回调验证 Token

### 操作

```bash
# OpenClaw 3.31+ 内置 QQ Bot 插件，直接启用
openclaw config set qqbot.enabled true
openclaw config set qqbot.appId "your-app-id"
openclaw config set qqbot.appSecret "your-app-secret"
openclaw config set qqbot.token "your-token"

# 重启 Gateway
openclaw gateway restart
```

### 验证标准
- `openclaw gateway logs` 中看到 QQ Bot 连接成功
- 向机器人发私聊消息，OpenClaw 日志中能看到消息事件
- （此时机器人由 OpenClaw 内置 Agent 回复，非 Java Agent）

## 步骤 3：Java 侧新增 POST 端点

**负责人**：Java 开发
**依赖**：无，可与步骤 1/2/4 并行
**预计耗时**：30 分钟（含测试）

### 新增文件

`src/main/java/com/manus/aiagent/gateway/controller/AgentRelayController.java`

```java
package com.manus.aiagent.gateway.controller;

import com.manus.aiagent.gateway.AgentGateway;
import com.manus.aiagent.gateway.model.GatewayRequest;
import com.manus.aiagent.gateway.model.GatewayResponse;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.web.bind.annotation.*;

/**
 * Agent 中继端点：供 OpenClaw 等外部 Gateway 通过 HTTP 调用 Java Agent
 */
@RestController
@RequestMapping("/gateway")
@RequiredArgsConstructor
@Slf4j
public class AgentRelayController {

    private final AgentGateway agentGateway;

    /**
     * 同步对话端点，供外部 Gateway（OpenClaw、飞书等）调用
     */
    @PostMapping("/agent/chat")
    public GatewayResponse handleAgentChat(@RequestBody GatewayRequest request) {
        log.info("[Relay] 收到外部请求: source={}, mode={}, chatId={}",
                request.getSource(), request.getMode(), request.getChatId());

        GatewayResponse response = agentGateway.chatSync(request);

        log.info("[Relay] 响应: success={}, contentLength={}",
                response.isSuccess(),
                response.getContent() != null ? response.getContent().length() : 0);

        return response;
    }
}
```

### 说明
- 这是一个**新的 Controller**，不替代现有的 `GatewayController`（已标记 @Deprecated）
- 端点路径：`POST /api/gateway/agent/chat`
- 请求格式：JSON，与现有 `GatewayRequest` 完全兼容
- 响应格式：JSON，即 `GatewayResponse`（含 content, chatId, success, errorMessage）

### 请求示例

```json
POST /api/gateway/agent/chat
Content-Type: application/json

{
  "message": "你好，帮我查一下今天的天气",
  "chatId": "qq_group_abc123",
  "mode": "normal",
  "source": "qq"
}
```

### 响应示例

```json
{
  "content": "今天北京的天气是晴，气温 18-25°C...",
  "chatId": "qq_group_abc123",
  "success": true,
  "errorMessage": null
}
```

### 验证标准
- `curl -X POST http://localhost:8123/api/gateway/agent/chat -H "Content-Type: application/json" -d '{"message":"你好","chatId":"test_001","mode":"normal","source":"test"}'` 返回正常响应

## 步骤 4：开发 OpenClaw Relay Skill

**负责人**：Node.js/后端
**依赖**：步骤 1 完成（可与步骤 3 并行）
**预计耗时**：2-3 小时（含调试）

### 4.1 创建 Skill 项目

```bash
mkdir -p ~/.openclaw/skills/agent-relay
cd ~/.openclaw/skills/agent-relay
npm init -y
```

### 4.2 编写 Skill

`~/.openclaw/skills/agent-relay/index.ts`

```typescript
import { defineSkill } from "openclaw/plugin-sdk";

const JAVA_AGENT_URL = process.env.JAVA_AGENT_URL || "http://localhost:8123/api";

export default defineSkill({
  id: "agent-relay",
  name: "Java Agent Relay",
  description: "将消息转发到 Java Agent 处理并返回结果",

  async run(ctx) {
    const message = ctx.message?.text;
    if (!message) return "未收到消息";

    const chatId = ctx.message?.chatId || "unknown";

    try {
      const response = await fetch(`${JAVA_AGENT_URL}/gateway/agent/chat`, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({
          message,
          chatId: `qq_${chatId}`,
          mode: "normal",
          source: "qq",
        }),
      });

      const data = await response.json();
      if (data.success) {
        return data.content;
      }
      return `处理失败: ${data.errorMessage}`;
    } catch (error) {
      return `Java Agent 调用失败: ${error.message}`;
    }
  },
});
```

### 4.3 注册 Skill 到 QQ 频道

```bash
# 将 skill 绑定到 QQ Bot 渠道
openclaw config set qqbot.defaultSkill "agent-relay"

# 重启 Gateway
openclaw gateway restart
```

### 验证标准
- QQ 用户向机器人发消息 → OpenClaw 日志显示调用了 agent-relay skill
- Java Agent 日志显示收到请求并处理
- QQ 用户收到 Java Agent 的回复

## 步骤 5：端到端联调

**负责人**：全员
**依赖**：步骤 1-4 全部完成
**预计耗时**：1-2 小时

### 测试场景

| 场景 | 操作 | 预期结果 |
|------|------|----------|
| 私聊-普通模式 | QQ 私聊机器人 "你好" | OpenFriend 正常回复 |
| 私聊-超级模式 | 发送 "#super 帮我查天气" | ManusAgent 工具调用后回复 |
| 群聊-@机器人 | 群里 @机器人 "今天有什么新闻" | 正常回复 |
| 断线重连 | 手动 kill OpenClaw 再启动 | QQ 消息自动恢复 |
| Java Agent 不可用 | 停止 Java Agent，QQ 发消息 | 返回友好错误提示 |

### 完成标准
- 以上 5 个场景全部通过
- 在测试群稳定运行 24 小时无异常

## 步骤 6（可选）：容器化部署

```yaml
# docker-compose.yml
version: "3.8"
services:
  java-agent:
    build: .
    ports:
      - "8123:8123"
    environment:
      - SPRING_PROFILES_ACTIVE=prod

  openclaw:
    image: openclaw/openclaw:latest
    ports:
      - "18789:18789"
    environment:
      - JAVA_AGENT_URL=http://java-agent:8123/api
    volumes:
      - ./openclaw-config:/root/.openclaw
    depends_on:
      - java-agent
```
